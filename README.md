Учебный проект с демонстрацией классических проблем многопоточности
и способов их решения. Каждая демонстрация запускается из консольного меню.


TwoStreams - **Задача:** два потока поочерёдно печатают `1` и `2` с интервалом 1 секунда.

LiveLock - **Задача:** реализовать программу которая получает LiveLock.

DeadLock - **Задача:** реализовать программу которая получает DeadLock.
